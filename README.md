

## Naming convention (sets the `doc_type` metadata used in filtering and citations)

| Prefix        | doc_type     |
|---------------|--------------|
| `fees_`       | fees         |
| `terms_`      | terms        |
| `regulatory_` | regulatory   |
| `faq_`        | faq          |
| `product_`    | product      |
| anything else | general      |

Example: `fees_current-account-fees-and-information.pdf`.
